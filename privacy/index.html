Spark Education Technology LLC ("Spark," "we," or "us") provides the Spark Filter browser extension. This policy explains what the extension processes and how it is used.

01

Information the extension processes

Spark Filter processes limited browser page signals to identify browser games, proxy runtimes, and administrator-configured blocklist matches. These signals can include the current page address, navigation state, page text patterns, script and resource URLs, rendering behavior, keyboard or pointer-lock behavior, and related browser runtime signals.

The extension may also create diagnostic records when developer diagnostics are enabled. These records are stored locally in the browser and are intended to explain detector decisions.

✓

Spark Filter does not request or intentionally collect: Names, email addresses, passwords, authentication tokens, financial or health information, private messages, contacts, or precise location information.

02

How information is used

The extension uses page signals only to:

  • detect browser games and proxy runtimes;
  • apply local and administrator-configured blocking rules;
  • show local diagnostics and explain detector decisions; and
  • maintain local settings, cached results, and blocklists.

Spark does not use this information for advertising, credit decisions, lending, or unrelated profiling.

03

Network communication

When an administrator configures a distribution endpoint, Spark Filter periodically requests shared blocklists and detector-rule configuration from that endpoint. The request contains no browsing history, page contents, student records, account identifiers, or detector session reports. The extension stores the last valid configuration locally so blocking continues if the endpoint is unavailable.

Spark Filter can also retrieve administrator-approved public blocklists. Those requests are made to the URLs configured by the administrator.

The backend stores shared configuration data such as domains and detector signal weights. It is not designed to receive or store browsing telemetry.

04

Storage and retention

Detector state, settings, diagnostic records, cached results, and blocklists are stored in the browser's local extension storage. Administrators can clear or replace managed configuration. Cached remote configuration remains only until it is replaced, cleared, or invalidated by the extension.

Spark does not retain page-level browsing data on its servers through the normal operation of the extension.

05

Sharing

Spark does not sell user information or transfer it to third parties for advertising or unrelated purposes. Configuration requests go to the administrator-configured distribution endpoint and configured blocklist sources. Any school or organization using Spark remains responsible for approving the extension and configuring it for its environment.

06

Children and schools

Spark Filter is an administrator-deployed browser tool and is not designed to collect personal information from children. Schools and districts should review the extension, provide any notices required by their policies, and establish appropriate agreements before deployment. Where applicable, the school or district determines the permitted educational purpose, access controls, retention settings, and deletion process.

07

Security

We use reasonable technical measures appropriate to the service. No method of storage or transmission is completely secure. Administrators should protect distribution write credentials and limit access to managed configuration systems.

08

Changes to this policy

We may update this policy when the extension or its data practices change. The effective date above will be updated when changes are made.

09

Questions about privacy?

For privacy questions or requests, contact Spark Education Technology LLC.
