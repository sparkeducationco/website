# Self-hosted fonts

Downloaded from Google Fonts on 2026-09-30. The files are unmodified WOFF2 Latin subsets from the official Google Fonts service.

- `barlow-condensed-latin-700.woff2`: Barlow Condensed, normal style, weight `700`. License: `Barlow-Condensed-OFL.txt`.
- `manrope-latin-variable.woff2`: Manrope, normal style, variable weight descriptor `400 700`. License: `Manrope-OFL.txt`.
- `instrument-serif-latin-400.woff2`: Instrument Serif, normal style, weight `400`. License: `Instrument-Serif-OFL.txt`.
- `instrument-serif-latin-400-italic.woff2`: Instrument Serif, italic style, weight `400`. License: `Instrument-Serif-OFL.txt`.

Instrument Serif is the current display face; Manrope is used for navigation and body text. Barlow Condensed is retained as an unused asset from the earlier design.

Use `font-display: swap` when declaring these fonts.
